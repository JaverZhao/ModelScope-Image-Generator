# ModelScope AI 绘图助手 - 详细开发任务计划清单
## 项目概述
- **项目名称**: ModelScope Image Generator (MS-Gen)
- **技术栈**: Python 3.8+ / Streamlit / Requests / Pillow / JSON
- **开发模式**: 敏捷迭代，按模块分阶段开发

## 📋 阶段二：后端核心模块开发
### 任务 2.1：API客户端封装
**优先级**: P0
#### 子任务 2.1.1：基础HTTP客户端类
- [ ] **创建 `src/api/modelscope_client.py`**
  - 定义 `ModelScopeClient` 类
  - 实现初始化方法（接收API Key）
  - 封装通用请求头构建逻辑
  - 实现基础 `GET` 和 `POST` 方法
  - 添加超时设置（连接超时5秒，读取超时30秒）
#### 子任务 2.1.2：图像生成API封装
- [ ] **实现提交生图任务方法 `submit_generation_task()`**
  - 参数：model, prompt, negative_prompt, size, steps, guidance_scale, seed, loras
  - 返回：task_id 或错误信息
  - 处理请求参数编码（`ensure_ascii=False`）
  - 添加异步模式请求头 `X-ModelScope-Async-Mode: true`
- [ ] **实现任务状态查询方法 `query_task_status()`**
  - 参数：task_id
  - 返回：任务状态字典（status, progress, output_images等）
  - 添加任务类型请求头 `X-ModelScope-Task-Type: image_generation`
- [ ] **实现轮询等待方法 `wait_for_completion()`**
  - 参数：task_id, timeout, poll_interval
  - 实现轮询逻辑（默认每5秒查询一次）
  - 支持自定义超时时间（默认300秒）
  - 返回最终状态和图片URL列表
#### 子任务 2.1.3：错误处理与重试机制
- [ ] **定义异常类**
  - `APIKeyInvalidError`: API Key无效
  - `TaskFailedError`: 任务失败
  - `NetworkError`: 网络错误
  - `QuotaExceededError`: 余额不足
  - `ContentViolationError`: 内容违规
- [ ] **实现错误解析逻辑**
  - 解析API返回的错误码和错误消息
  - 根据错误类型抛出对应异常
  - 记录错误日志
- [ ] **实现自动重试机制**
  - 网络错误自动重试3次
  - 指数退避策略（2秒、4秒、8秒）
#### 验收标准：
- ✓ 能够成功提交生图任务并获取task_id
- ✓ 能够正确查询任务状态
- ✓ 能够正确处理各种错误情况
- ✓ 单元测试覆盖率 > 80%

  - 删除记录数据

- [ ] **创建 `src/utils/image_processor.py`**
  - 实现 `save_image()` 方法：保存原始图片
  - 实现 `generate_thumbnail()` 方法：生成缩略图（固定宽度256px，保持比例）
  - 实现 `get_image_info()` 方法：获取图片尺寸、大小等元信息
  - 实现 `create_date_directory()` 方法：按日期创建存储目录
- [ ] **定义图片存储结构**
  - 目录结构：`data/images/YYYY-MM-DD/{record_id}_original.jpg`
  - 按日期自动创建文件夹：使用 `datetime.now().strftime("%Y-%m-%d")`
  - 原图命名：`{record_id}_original.jpg`
  - 缩略图命名：`{record_id}_thumb.jpg`
  - 记录ID生成：使用 `uuid.uuid4()` 生成唯一标识，可截取前8位作为短ID
- [ ] **实现图片保存逻辑**
  - 1. 根据当前日期创建文件夹路径（不存在则自动创建）
  - 2. 生成唯一的 record_id
  - 3. 下载并保存原图到 `{date_dir}/{record_id}_original.jpg`
  - 4. 生成缩略图并保存到 `{date_dir}/{record_id}_thumb.jpg`
  - 5. 返回原图路径和缩略图路径，供历史记录保存

#### 子任务：
- [ ] **创建业务流程控制器 `src/core/generation_service.py`**
  - 定义 `GenerationService` 类
  - 串联API调用、历史记录、图片下载流程
- [ ] **实现完整生图流程方法 `generate_image()`**
  1. 验证参数（prompt、model、size等）
  2. 创建历史记录（状态：pending，生成record_id）
  3. 提交API任务，获取task_id
  4. 更新历史记录（状态：processing，task_id）
  5. 轮询任务状态，直到成功或失败
  6. 如果成功：
     - 从URL下载图片
     - 按日期创建文件夹 `data/images/YYYY-MM-DD/`
     - 保存原图 `{record_id}_original.jpg`
     - 生成缩略图并保存 `{record_id}_thumb.jpg`
     - 更新历史记录（状态：succeed，图片路径）
  7. 如果失败：
     - 更新历史记录（状态：failed，错误信息）
  8. 返回结果（成功或失败的详细信息）
- [ ] **实现异常处理和回滚**
  - 任何步骤失败，更新历史记录状态为failed
  - 记录错误信息
  - 清理临时文件
#### 验收标准：
- ✓ 完整流程无阻塞运行
- ✓ 异常情况正确处理

## 📝 开发规范
### 代码规范
- 遵循 PEP 8 代码风格
- 使用类型注解
- 函数和类添加docstring
- 单个函数不超过50行
### Git提交规范
```
feat: 新功能
fix: 修复bug
docs: 文档更新
style: 代码格式
refactor: 重构
test: 测试
chore: 构建/工具
```
### 命名规范
- 文件名：小写下划线 `history_manager.py`
- 类名：大驼峰 `HistoryManager`
- 函数名：小写下划线 `get_record_by_id()`
- 常量：全大写下划线 `MAX_RETRY_COUNT`
